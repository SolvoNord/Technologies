# Projet industriel — photographies fournies par le propriétaire

Ces trois photographies réelles ont été fournies pour illustrer le projet « Un réseau industriel installé et configuré ».

1. `01-unboxing.webp` : déballage du FortiAP 432FR.
2. `02-antennas.webp` : raccordement des antennes et préparation.
3. `03-installed.webp` : point d’accès installé en environnement industriel.

Les JPEG d’origine sont préservés chez le propriétaire. Les fichiers WebP affichés sur le site conservent le cadre complet et l’orientation des photos; aucun objet ni contenu n’a été ajouté ou supprimé. Les métadonnées de prise de vue ne sont pas incluses dans les exports WebP.

La dernière image sert de couverture. Les trois étapes sont présentées dans les détails du projet avec légendes FR/EN. L’agrandissement utilise une boîte de dialogue native, les boutons précédent/suivant et les flèches du clavier. Échap ferme la vue et le focus revient à la photo d’origine.
