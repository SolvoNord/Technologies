# Installation d’un point d’accès industriel — photos du propriétaire

Ces trois photographies réelles illustrent la section générale « Sur le terrain ». Elles ne sont rattachées à aucune fiche projet.

1. `01-unboxing.webp` : déballage du FortiAP 432FR.
2. `02-antennas.webp` : branchement des antennes et préparation.
3. `03-installed.webp` : point d’accès installé en environnement industriel.

Les JPEG d’origine sont préservés chez le propriétaire. Les WebP conservent le cadre complet, les couleurs et l’orientation; leurs métadonnées de prise de vue ont été retirées. Aucun objet ou contenu n’a été ajouté ou supprimé.

Les trois étapes sont visibles dans une galerie autonome avec légendes FR/EN. L’agrandissement utilise une boîte de dialogue native et les boutons précédent/suivant ou les flèches du clavier. Échap ferme la vue et le focus revient à la photo d’origine.
